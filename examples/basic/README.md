# Example: price digest bot

A Telegram Serverless bot with three scheduled jobs:

| Job | Schedule (UTC) | What it does |
| --- | --- | --- |
| `syncPrices` | every 15 minutes | Fetches coin prices with `fetch` and upserts them into `prices`. |
| `dailyDigest` | 09:00 daily | Sends the prices to every subscriber. |
| `backup` | 02:30 daily | Exports all tables to NDJSON as a workflow artifact kept 14 days. |

Users subscribe with `/start` and leave with `/stop` (`tgcloud/handlers/message.js`).

## Run it

```bash
npm install
npx tgcloud login
npx tgcloud push && npx tgcloud migrate
npx tgcron check
```

Try a job against your local files before deploying it:

```bash
TGCLOUD_TOKEN=app123:... npx tgcron run syncPrices --local
```

`.github/workflows/tgcron.yml` was generated by `npx tgcron generate github`.
Copy the project into its own repository, add the `TGCLOUD_TOKEN` secret, and
the schedules start after the first push to the default branch.
